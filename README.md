# 🌐 Global Connector - Multilingual Chat Application

**Project No.1 from International Projects List**

### What is this project?
This is a multilingual chat app that allows people from different countries to chat in their own language. It breaks the language barrier for international teams.

### Problem It Solves
International teams can't communicate because of different languages. This app translates messages in real-time.

### Features
- Two users can chat at same time
- Select language: English, Urdu, French, Arabic, Spanish, German
- Real-time translation with free MyMemory API
- Mobile friendly design

### Tech Stack Used
- HTML, CSS, JavaScript
- MyMemory Free Translation API (No API key needed)

### Why International Project?
Because it is not for one country. It connects people from all over the world, different cultures and time zones. Useful for international companies, students and travelers.
